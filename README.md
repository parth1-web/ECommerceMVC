# 🛍️ ECommerceMVC

> ASP.NET Core MVC client application integrated with a custom E-commerce REST API.

## 📌 Overview

ECommerceMVC is the client-side web application for my E-commerce system.

It consumes the **ECommerceSolution ASP.NET Core Web API** and demonstrates how an MVC application can integrate with a backend REST API.

---

## ✨ Features

* User registration and login
* JWT-based authentication flow
* Product browsing
* Category browsing
* Shopping cart
* Wishlist
* Checkout
* Order confirmation
* My Orders
* Payment integration
* API-based data communication

---

## 🏗️ Architecture

```text
Browser
   │
   ▼
ASP.NET Core MVC
   │
   ├── Controllers
   │
   ├── Views
   │
   └── API Services
          │
          ▼
   ECommerceSolution API
          │
          ▼
   Database
```

## 🎯 Purpose

This project demonstrates practical experience integrating a frontend MVC application with a separately developed REST API.

It also demonstrates API service abstraction, authentication handling and end-to-end e-commerce workflows.
